## 📝 Sobre o Projeto

As resenhas foram produzidas ao longo do semestre letivo de **2026/1**, cobrindo artigos clássicos e contemporâneos da literatura de Engenharia de Software. O objetivo é desenvolver a capacidade de **leitura crítica**, **síntese acadêmica** e **conexão entre teoria e prática profissional**.

**Experiências pessoais referenciadas nas resenhas:**
- 🏭 **Estágio na ArcelorMittal Sistemas** — suporte a aplicações internacionais (International Application Support)
- 🛒 **MVP de E-commerce** — desenvolvido com Node.js, Prisma ORM, React e SQLite
- ⚡ **Projeto acadêmico de 5 dias** — uso de ferramentas de IA sob pressão de prazo com tecnologias desconhecidas

## 📐 Formato das Resenhas

Todas as resenhas seguem um modelo acadêmico padronizado com **quatro seções**:

| Seção | Descrição |
|-------|-----------|
| **1. Introdução** | Contextualização do artigo, seus autores, época de publicação e relevância |
| **2. Tema Central** | Síntese dos conceitos, argumentos e contribuições principais do artigo |
| **3. Conexão com a Prática Profissional** | Relação entre a teoria do artigo e experiências pessoais vividas |
| **4. Conclusão** | Avaliação crítica do artigo e sua aplicabilidade atual |

**Template LaTeX utilizado:**

## ⚙️ Como Compilar

Os arquivos `.tex` podem ser compilados de duas formas:

### Opção 1 — Tectonic (recomendado, local)

```bash
# Instalar o Tectonic
brew install tectonic   # macOS
# ou: cargo install tectonic

# Compilar um arquivo
tectonic Artigo_2_Criteria_Modularization.tex

# Compilar todos de uma vez
for f in *.tex; do tectonic "$f"; done
```

### Opção 2 — Overleaf (online)

1. Acesse [overleaf.com](https://www.overleaf.com)
2. Crie um novo projeto em branco
3. Cole o conteúdo do arquivo `.tex`
4. Compile e baixe o PDF
